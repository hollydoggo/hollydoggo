Temperature Monitor 

📊 Fan RPM Monitoring 

    CPU Fan RPM: Displays CPU fan speed dynamically based on CPU temperature 

    GPU Fan RPM: Displays GPU fan speed dynamically based on GPU temperature 

    RPM values update in real-time alongside temperature readings 

    Falls back to calculated RPM based on temperature if hardware sensors unavailable 

🔽 Transparent Overlay Mode 

"🔽 Overlay" Button: Click to enter overlay/minimize mode 

    When in overlay mode: 

    App window becomes transparent (80% opacity) 

    Window is borderless and stays on top 

    Automatically positions to top-right corner of screen 

    Removed from taskbar for cleaner desktop 

    Button text changes to "🔼 Expand" to exit overlay 

    Click "🔼 Expand" to return to full window mode with all controls visible 

Enhanced UI 

    Larger panels for CPU and GPU with dedicated fan RPM display 

    Color-coded progress bars matching temperature ranges 

    Professional dark theme throughout 

    Better spacing and visual hierarchy 

    Usage 

    Launch the app to see real-time CPU/GPU temperatures and fan speeds 

    Click "🔽 Overlay" to minimize to a compact transparent overlay 

    Click "🔼 Expand" while in overlay mode to restore full window 

    Temperatures displayed in Celsius 

    Fan speeds displayed in RPM (Revolutions Per Minute)
